# Тренажёр Replay

**Открыть на телефоне:** https://hanslandazieg-ship-it.github.io/replay/

**Приложение для Windows:** [скачать ReplayTrainer.exe](windows/ReplayTrainer.exe) → на странице файла кнопка «Download raw file». При первом запуске Windows может предупредить: «Подробнее» → «Выполнить в любом случае».

Бэктест-тренажёр EUR/USD и GER40 в стиле FX Replay: японские свечи от 3 минут до недели, симулятор рынка с демо-счётом, инструмент «Позиция» с расчётом объёма под риск, рисование, коробки торговых сессий по МСК и новости Forex Factory.

## На айфоне

1. Откройте адрес сайта в **Safari**.
2. Нажмите «Поделиться» → «На экран Домой».
3. Запускайте с иконки «Replay». Работает без интернета, сделки и рисунки хранятся на телефоне.

## Как обновляются данные

Каждый день в 07:23 по Москве GitHub Actions запускает `tools/update_data.py`. Скрипт докачивает новые дни минутных котировок Dukascopy (собирает их в 3-минутные свечи) и свежие новости Forex Factory, сохраняет их в `data/` и публикует сайт заново. Запустить вручную: вкладка **Actions** → «Котировки и публикация» → **Run workflow**.

Если Forex Factory не пустит сервер GitHub, новости возьмутся из их недельного календаря — там нет фактических значений, только прогноз и предыдущее.

## Файлы

- `index.html` — приложение целиком
- `data/EURUSD.txt`, `data/GER40.txt` — котировки (компактный формат, 3-минутные свечи Bid)
- `data/news.json` — новости EUR и USD среднего и сильного влияния
- `sw.js`, `manifest.webmanifest`, `icons/` — работа как приложение на телефоне
